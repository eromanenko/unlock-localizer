# PWA "Unlock! Helper" — План розробки (Vanilla JS)

## 1. Скоуп та функціональність
*   **Ігри**: Всі доступні (~75 пригод). Дані про структуру беруться з `Unlock.json`, де `ID` — це назва коробки, а `adventures` — масив ігор в ній.
*   **Мови**: Мультимовний інтерфейс і контент: **EN / UK / RU**.
    *   *Відкладений переклад*: Автоматичний переклад не робимо. Якщо локалізації для гри немає, відповідна кнопка мови (або опція в меню) для цієї гри буде відсутня (схована).
    *   **Fallback**: Якщо англійської локалізації немає, замість неї тимчасово відображатимемо французьку (оскільки вона є скрізь).
    *   **Локалізація інтерфейсу**: Загальні елементи UI (кнопки "Код", "Підказка", "Скинути", повідомлення "Візьміть карту" тощо) беруться з глобальних файлів локалізації в `assets/GameData/Locale/{Language}/locale.json`.
    *   **Динамічність**: Перемикати мову можна в будь-який момент (навіть коли відкрите вікно повідомлення, текст має одразу оновитися). При додаванні нового файлу локалізації в майбутньому він має підхоплюватися автоматично.
*   **Механізми (`machines`)**: Не підтримуються.
*   **Таймер**: Не потрібен.
*   **Ігрові події (`events`)**: На цій ітерації пропускаємо.

## 2. Функціонал гравця
*   **Ввести код**: Гравець вводить 4-цифровий код. Логіка обробки залежить від значення `type` у відповідному об'єкті масиву `codes`:
    *   **Code**: Відображається локалізоване повідомлення та інструкції (які карти взяти/скинути).
    *   **Sound**: Оскільки PWA не підтримує складні звукові пазли, виводиться прохання до гравця ввести цей код в оригінальному застосунку "Unlock!".
    *   **Інші типи** (`Normal`, `Dial`, `Error`, `End` тощо): Поки що відображаються як звичайні повідомлення (буде уточнюватися за потреби).
*   **Ввести карту (підказки та рішення)**: Гравець вводить номер карти. Відображається екран, де всі можливі підказки (і рішення, якщо є) сховані під спойлерами. Гравець натискає на спойлери, щоб по черзі їх відкривати.
*   **Приховані предмети (`hiddenObjects`)**: Окрема кнопка на екрані гри.
    *   Якщо в грі немає прихованих предметів — кнопка заблокована (disabled).
    *   Якщо є — відкривається екран зі списком "таймінгів" (наприклад, "900", "300") у вигляді спойлерів. Натискання на таймінг показує текст про прихований предмет.

## 3. UX, Дизайн та Ресурси
*   **Стартовий екран (Каталог)**: Плитки з іграми, які згруповані за "коробками" (на основі `Unlock.json`). 
    *   *Коробки*: Зображення для коробок лежать у `C:\Projects\GAMES\unlock-localizer\assets\images\covers\` (напр. `Short.png`).
    *   *Ігри*: Іконки для кожної гри копіюватимуться з `C:\migration\bg\Unlock\assets\Unlock_18_9_APKPure\unlock\assets\bin\Data\exported\Assets\Texture2D\`. Назва файлу (напр. `SherlockHead.png`) точно відповідає назві гри у масиві `adventures` в `Unlock.json`.
*   **Фони та Спрайти**:
    *   Для фону екрану гри використовується відповідний файл `*_fond.jpg` з папки `Skins`.
    *   Поруч лежать спрайти з аналогічними назвами (без `_fond`), які будуть використовуватися для кнопок/UI.
*   **Офлайн-режим (PWA)**:
    *   Застосунок має працювати офлайн (через Service Worker).
    *   JSON-файли ігор будуть знаходитись у папці застосунку і кешуватимуться.
    *   Зображення кнопок, обкладинки коробок та іконки ігор включаються в кеш PWA. Фони (`*_fond.jpg`) на цій ітерації **не кешуються** через service worker.

### JSON Schema Cheat-Sheet (для розробки)
Щоб не втратити контекст структури даних при написанні коду:
*   `codes`: масив об'єктів `{ number, type, cardsToTake, cardsToDiscard, message }`
*   `hints`: масив об'єктів `{ number, hasMoreHint, hasSolution, message }`
*   `answers`: масив об'єктів `{ hintNumber, message, cards, code }`
*   `hiddenObjects`: масив об'єктів `{ number, time, message }`
*   Локалізація лежить в `locale.json` у вигляді `{ language, localizations: { key: value } }`

### Розробка UI/UX (Vanilla JS)
*   Структура SPA (Single Page Application) на Vanilla JS з модулями або класами для логіки.
*   **Держава (State Management)**: Об'єкт стану, що тримає поточну гру, вибрану мову, і дані гри. Реактивне оновлення DOM при зміні мови (або ручне перемальовування компонентів).
*   **View: Catalog**: Генерація DOM для списку коробок і плиток ігор, використовуючи оригінальний `Unlock.json` та заздалегідь скопійовані зображення.
*   **View: Game**: 
    *   Завантаження фону і спрайтів гри.
    *   DOM для блоку кнопок мов (приховати ті, що відсутні, fallback на FR для EN).
    *   Кнопка "Код", інпут "Номер карти", кнопка "Приховані предмети".
*   **View: Modals/Overlays**: Спливаючі вікна або секції для:
    *   Результат введення коду.
    *   Спойлери підказок (елементи `<details>` + `<summary>` або кастомні div'и).
    *   Спойлери прихованих предметів.

### Інфраструктура PWA
*   `manifest.webmanifest`.
*   `sw.js` (Service Worker) з використанням Workbox або Vanilla JS для кешування HTML/CSS/JS, папок `data/` та UI зображень. Виключення для фонів `*_fond.jpg`.
